Сначала включите безопасный DNS (Secure DNS)\n    * В Chrome откройте "Использовать безопасный DNS" и укажите поставщика DNS, выбрав вариант не "Поставщик по умолчанию"\n    * В Firefox включите "DNS через HTTPS", установите режим "Персональный", нажмите "Выбрать провайдера/поставщика" и вручную укажите URL. Например, `https://dns.google/dns-query` (Cloudflare может быть заблокирован)\n    * Windows 11 позволяет включить Secure DNS в настройках самой ОС — [инструкция](https://remontka.pro/dns-over-https-windows-11/). Для Windows 11 этот способ рекомендуется\n    * Владельцам роутеров Keenetic нужно активировать в настройках опцию "Транзит запросов". Если её выключить, Secure DNS на компьютере может работать неправильно\n\n2. Загрузите zip/rar-архив с [последнего релиза](https://github.com/Glowaearouse/zapret-discord-youtube/releases/latest)\n\n3. Откройте свойства архива и включите флажок "Разблокировать". При использовании 7-Zip или PeaZip этот пункт можно не выполнять\n\n4. Распакуйте архив в путь без кириллицы и специальных символов\n\n5. Запустите подходящий файл\n    * Чтобы найти рабочую стратегию, откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`\n    * Для автоматического запуска выберите **`service.bat`** -> `Install Service` -> подходящую стратегию\n\n## ℹ️Краткие описания файлов\n\n- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии\n\n  Такой запуск удобен для проверки стратегий. Результат зависит от множества условий, поэтому **перебирайте разные варианты (ALT, FAKE и другие), пока не найдёте подходящий именно вам**\n\n- [**`service.bat`**](./service.bat) — установка автозапуска и дополнительные операции:\n  - <ins>**`Install Service`** — добавление выбранной стратегии в автозапуск (services.msc)</ins>\n  - **`Remove Services`** — удаление стратегии и WinDivert из служб\n  - **`Check Status`** — просмотр состояния обхода и служб, включая стратегию в автозапуске и WinDivert\n  - **`Game Filter`** — смена режима обхода для игр и других сервисов, работающих с UDP и TCP на портах выше 1023.  \n  **После изменения обязательно перезапустите стратегию.**  \n  В скобках показывается текущее состояние: включено или выключено.\n  - **`IPSet Filter`** — переключение обхода для сервисов из `ipset-all.txt`.  \n  Опция полезна при проверке ресурса, который без zapret не работает  \n  В скобках отображается состояние:\n    - `none` — ни один IP не проверяется\n    - `loaded` — IP проверяется на наличие в списке\n    - `any` — под фильтр попадает любой IP  \n  - **`Auto-Update Check`** — включение или отключение автоматической проверки обновлений\n  - **`Replace active fakes`** — замена используемого фейка на другой из каталога `bin`\n  - **`Update IPSet List`** — получение актуального `ipset-all.txt` из репозитория\n  - **`Update Hosts File`** — обновление hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>\n  - **`Check for Updates`** — ручная проверка обновлений\n  - **`Run Diagnostics`** — поиск распространённых причин неисправности zapret.  \n  В конце доступна очистка кэша <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это может вернуть работу приложения, если оно неожиданно перестало открываться\n  - **`Run Tests`** — утилита для проверки стратегий:\n    - `Standard tests` — проверка сайтов из `utils/targets.txt`\n    - `DPI checkers` — проверка DPI у разных провайдеров, включая Cloudflare и Amazon\n\n\n## ☑️Распространенные вопросы и проблемы\n\n### После запуска скрипта `general*` ничего не происходит\n\n- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться winws.exe (обход), видимый на панели задач.  \nЕсли его нет, обратитесь к [#522](https://github.com/Glowaearouse/zapret-discord-youtube/issues/522)\n\n### Ни одна стратегия не подходит\n- Откройте командную строку с правами администратора\n- По очереди выполните:\n\n    `netsh winsock reset`\n  \n    `netsh int ip reset all`\n  \n    `netsh winhttp reset proxy`\n  \n    `ipconfig /flushdns`\n  \n- Перезагрузите компьютер\n\n### Не работает телеграм (веб версия)\nВ **`service.bat`** выберите **`Update hosts file`**. Если hosts устарел, программа предложит обновить его вручную:  \n  - Скопируйте весь текст из открытого блокнота\n  - От имени администратора откройте текстовым редактором файл `hosts` в созданной папке\n  - Вставьте скопированное в конец `hosts` или замените прежние аналогичные строки\n  - Сохраните файл и проверьте подключение ещё раз. Если результата нет, убедитесь, что изменения действительно сохранились.\n\n#### Работа не гарантируется. Если способ не помог, установите [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) и подключите [локальный прокси](https://github.com/Glowaearouse/tg-ws-proxy) либо любой публичный прокси.\n\n### Обход не работает / перестал работать\n\n> [!IMPORTANT]\n> **Стратегии могут терять работоспособность со временем.**\n> Стратегия способна некоторое время работать, а затем перестать из-за обнаружения.\n> Здесь собрано много разных стратегий обхода. Если готовые варианты не помогают, создайте новую на основе одной из них и измените её параметры.\n> Описание параметров находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).\n\n- В `service.bat` -> `Run Diagnostics` проверьте отсутствие ошибок\n\n- Проверьте, присутствует ли адрес ресурса в доменных или IP-списках\n\n- Запустите другие стратегии, например **`ALT`** или **`FAKE`**\n\n- Выполните полную переустановку по инструкции ниже\n\n- Дополнительная информация: [#765](https://github.com/Glowaearouse/zapret-discord-youtube/issues/765)\n\n### Как переустановить/обновить полностью?\n- Сохраните добавленные вами ресурсы и данные\n- Перезапустите устройство\n- Выполните `service.bat` -> `Remove Services`\n- Запустите `service.bat` -> `Run Diagnostics`; при ошибках исправьте их, затем в конце выберите Y\n- Удалите каталог с запретом\n- Скачайте свежую версию [со страницы релизов](https://github.com/Glowaearouse/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)\n- Через ПКМ откройте свойства архива. Если внизу справа есть "Разблокировать", нажмите её, затем "Применить" и "ОК"\n- Распакуйте архив в новую папку в корне диска, без пробелов и специальных символов\n- Запускайте разные `general`-скрипты и проверяйте ресурсы. Если доступ не появился, завершите программу через значок замка на панели задач и попробуйте другую стратегию\n- После выбора рабочей стратегии включите автозапуск: `service.bat` -> `Install Service` -> нужная стратегия\n\n### Не работает игра/приложение с включённым запретом\n\n- В `service.bat` проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может повлиять на неожиданные ресурсы.\n\n### Античит ругается на WinDivert\n\n- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide\n\n### Требуется цифровая подпись драйвера WinDivert (Windows 7)\n\n- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)\n\n### При удалении с помощью [**`service.bat`**](./service.bat), WinDivert остается в службах\n\n1. Найдите имя службы командой в Windows: Win+R, затем `cmd`:\n\n```cmd\ndriverquery | find "Divert"\n```\n\n2. Остановите и удалите найденную службу:\n\n```cmd\nsc stop название_из_первого_шага\n\nsc delete название_из_первого_шага\n```\n\n### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube\n\n- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование)\n- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться\n- Если прежняя стратегия перестала работать, переберите остальные\n- См. также [#251](https://github.com/Glowaearouse/zapret-discord-youtube/discussions/251)\n\n### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord\n\n- Убедитесь, что [Secure DNS](#%EF%B8%8Fиспользование) настроен\n- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить её\n- В `service.bat` откройте `Run Diagnostics` и очистите кэш Discord\n- Проверьте приложение Discord после очистки кэша\n- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, ей можно пользоваться\n- Если Discord не работает и в браузере, снова проверьте все стратегии: YouTube и Discord могут работать на разных вариантах\n- См. также [#252](https://github.com/Glowaearouse/zapret-discord-youtube/discussions/252)\n\n### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram\n\n- Используйте [tg-ws-proxy](https://github.com/Glowaearouse/tg-ws-proxy)\n- Либо подключите бесплатный MTProto-прокси из интернета\n\n### Не работают игры\n\nИгр много, поэтому проверить и исправить каждую отдельно невозможно.\n\nНачните с универсальной последовательности:\n- через `service.bat` обновите ipset и активируйте `Game Filter`\n- если это не сработало, дополнительно включите `ipset any`\n\nУчтите: с `ipset any` многие сайты могут перестать открываться. Не оставляйте этот режим включённым постоянно. Определите IP-адреса, которые использует игра, и добавьте их в `ipset-all.txt`\n\nЕсли проблема останется, создайте обсуждение в [Discussions](https://github.com/Glowaearouse/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.\n\n### Не нашли своей проблемы\n\n- Опишите её [здесь](https://github.com/Glowaearouse/zapret-discord-youtube/issues)\n\n## 🗒️Добавление адресов прочих ресурсов\n\nДополнительные адреса можно указывать в следующих файлах:\n- **`list-general-user.txt`** — домены; поддомены учитываются автоматически\n- **`list-exclude-user.txt`** — домены-исключения, например когда сеть уже есть в `ipset-all.txt`, но конкретный домен фильтровать не нужно\n- **`ipset-all.txt`** — IP-адреса и подсети\n- **`ipset-exclude-user.txt`** — IP-адреса и подсети, которые нужно исключить\n  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`\n\n## ⭐Поддержка проекта\n\nПоддержать проект можно, поставив :star: этому репозиторию в правом верхнем углу страницы\n\nФинансовая поддержка автора исходного zapret доступна [здесь](https://github.com/bol-van/zapret?tab=readme-ov-file#%D0%BF%D0%BE%D0%B4%D0%B4%D0%B5%D1%80%D0%B6%D0%B0%D1%82%D1%8C-%D1%80%D0%B0%D0%B7%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D1%87%D0%B8%D0%BA%D0%B0)\n\n## ⚖️Лицензирование\n\nПроект распространяется по лицензии [MIT](https://github.com/Glowaearouse/zapret-discord-youtube/blob/main/LICENSE.txt)\n\n## 🩷Благодарность участникам проекта\n\n[![Contributors](https://contrib.rocks/image?repo=Glowaearouse/zapret-discord-youtube)](https://github.com/Glowaearouse/zapret-discord-youtube/graphs/contributors)\n\n💖 Особая благодарность автору [zapret](https://github.com/bol-van/zapret) — [bol-van](https://github.com/bol-van)
